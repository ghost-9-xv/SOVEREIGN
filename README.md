# SOVEREIGN

An open-source intelligence amplification layer for AI agents, combining adaptive polymathic expertise, evidence-driven reasoning, pattern analysis, recursive evaluation, JEV-inspired decision support, persistent memory, and controlled self-improvement.

## Overview

SOVEREIGN elevates existing AI agents from probabilistic text generators to reliable, evidence-driven engineering systems. Rather than relying on unverified generation, SOVEREIGN enforces a rigorous governing cycle:

```
UNDERSTAND -> RESEARCH -> DECOMPOSE -> SELECT_EXPERTISE -> PLAN -> EXECUTE -> OBSERVE -> CLASSIFY -> ANALYZE_PATTERNS -> EVALUATE -> DIAGNOSE -> REPAIR -> RETEST -> VERIFY -> RECORD -> LEARN -> IMPROVE
```

## Core Modules

- **Core & Security (`sovereign.core`, `sovereign.security`)**: Explicit task states, objective decomposition, tool contracts, permission verification, sandboxing limits, and least-privilege security enforcement.
- **Adaptive Polymath (`sovereign.polymath`)**: Context-sensitive expertise selection, principle research registry, and structured expertise cards.
- **JEV-Inspired Decision Engine (`sovereign.decision_engine`)**: Typed semantic judgments (`CHOICE`, `SCORE`, `NOUL`), schema validation, threshold policies, and provider-independent adapters.
- **Evaluator & Repair (`sovereign.evaluator`, `sovereign.repair`)**: Independent completion and policy verification, failure classification, root-cause diagnosis, targeted repair, and bounded retry controls.
- **Pattern Analysis (`sovereign.pattern_analysis`)**: Observation ingestion, deterministic aggregation, pattern discovery, semantic classification, evidence/counterevidence tracking, and longitudinal analysis.
- **Memory & Outcome Graph (`sovereign.memory`, `sovereign.outcome_graph`)**: Categorized persistent memory with provenance tracking and evidence-linked outcome traceability graphs for decision replay.

## Getting Started

### Installation

```bash
git clone https://github.com/sovereign-ai/sovereign.git
cd sovereign
pip install -e .
```

### Running Tests

```bash
pytest
```

## Core Governing Principles

1. **Outcome over output**: A task is complete only when required outcomes pass verified acceptance criteria.
2. **Evidence before confidence**: Ground conclusions in observed facts and verifiable execution traces.
3. **Simplicity before ambition**: Prefer the simplest adequate design (YAGNI / KISS).
4. **Deterministic enforcement**: Enforce security rules and permissions deterministically.
