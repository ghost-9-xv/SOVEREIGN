# Security Policy

## Security Principles

1. **Least Privilege**: Components and subtasks operate strictly under minimum required permissions.
2. **Deterministic Enforcement**: Authorization and security rules cannot be overridden by prompt content or semantic judgements.
3. **Prompt-Injection Resistance**: Retrived data and untrusted inputs are treated as data, not instructions.
4. **Secret Protection**: Credentials and sensitive tokens must never be hardcoded or logged.

## Reporting Vulnerabilities

If you discover a security vulnerability in SOVEREIGN, please report it directly to the security team rather than opening a public issue.

Contact: security@sovereign-ai.org (or submit a private security advisory on GitHub).
